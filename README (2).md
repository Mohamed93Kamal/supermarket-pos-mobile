## 🚀 التثبيت

### المتطلبات

- Python 3.8+
- pip
- (اختياري) Buildozer لبناء APK

### التثبيت على الكمبيوتر (للاختبار)

```bash
# 1. استنساخ المشروع
git clone https://github.com/YOUR_USERNAME/supermarket-pos-mobile.git
cd supermarket-pos-mobile

# 2. تثبيت المكتبات (Windows)
install.bat

# أو (Linux/Mac)
pip install -r requirements.txt

# 3. تشغيل التطبيق
python app_final.py

# أو (Windows)
run.bat
```

### تسجيل الدخول الافتراضي

```
Username: admin
Password: admin123
```

## 📦 بناء APK

### الطريقة 1: Google Colab (الأسهل)

1. افتح ملف `⚡-الحل-الفوري.txt`
2. اتبع التعليمات خطوة بخطوة
3. ارفع `app_final.py` و `supermarket.db`
4. انتظر 20-40 دقيقة
5. حمّل APK

### الطريقة 2: GitHub Actions (تلقائي)

سيتم بناء APK تلقائياً عند كل push!

### الطريقة 3: Buildozer محلياً (Linux/Mac)

```bash
# 1. تثبيت Buildozer
pip install buildozer

# 2. تثبيت المتطلبات
sudo apt-get install -y git zip unzip openjdk-17-jdk autoconf libtool

# 3. بناء APK
buildozer android debug

# 4. APK سيكون في
bin/supermarketpos-3.0.0-debug.apk
```
